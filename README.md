# 🤝 MirTimeTrade v1.0.0

**Безопасная система обмена предметами и игровой валютой между игроками через интерактивное GUI-меню** для серверов Minecraft (**Paper / Purpur 1.21+**), разработанная для проекта **Mir-Time**.

---

## 🌟 Основные возможности

### 1. Удобный и защищённый обмен (`/trade`)
* Отправка запроса на обмен командой `/trade <ник>` или нажатием `Shift + ПКМ` прямо по игроку в мире.
* Удобное двустороннее графическое меню (GUI), разделённое на левую и правую половины для полного визуального контроля предметов обеих сторон.
* Поддержка передачи любых кастомных предметов (включая артефакты из **MirTimeItems**), зачарованных книг, зелий и шалкеров с сохранением всех NBT-тегов.

### 2. Обмен игровой валютой (Интеграция с Vault)
* Встроенные кнопки прямо в меню трейда для добавления или уменьшения суммы игровой валюты (`+100$`, `+1000$`, `+10000$`) к предложению обмена.
* Автоматическая проверка баланса обоих игроков перед завершением сделки.

### 3. Многоуровневая защита от обмана (Anti-Scam)
* **5-секундный таймер подтверждения:** после нажатия кнопки готовности обоими игроками запускается обратный отсчёт перед финальной передачей вещей.
* **Автоматический сброс готовности:** если один из игроков меняет предмет в слоте или изменяет сумму валюты, статус готовности обеих сторон мгновенно сбрасывается.
* **Защита от потерь:** при закрытии меню или выходе одного из игроков с сервера все выставленные предметы безопасно возвращаются владельцам в инвентарь.

## ⌨️ Команды и права (Permissions)

| Команда | Алиасы | Описание | Право |
| :--- | :--- | :--- | :--- |
| `/trade <ник>` | `/обмен` | Отправить запрос на безопасный обмен игроку | `mirtime.trade.use` |
| `/trade accept` | `/обмен принять` | Принять входящий запрос на обмен | `mirtime.trade.use` |
| `/trade deny` | `/обмен отказать` | Отклонить входящий запрос на обмен | `mirtime.trade.use` |
| `/trade toggle` | — | Включить или выключить приём запросов на обмен | `mirtime.trade.use` |
| `/trade reload` | — | Перезагрузить `config.yml` без перезапуска сервера | `mirtime.trade.reload` |

### Дополнительные права
* `mirtime.trade.distance.bypass` — отправка запросов на обмен на любом расстоянии (даже в разных мирах).

## 📦 Установка

1. **Скачайте плагин из раздела Releases:**
   * Перейдите во вкладку **[Releases](../../releases)** в правой части страницы репозитория.
   * Выберите последний актуальный выпуск (например, `v1.0.0`).
   * В блоке **Assets** нажмите на файл `MirTimeTrade-1.0.0.jar`, чтобы скачать его.
2. **Установите на сервер:**
   * Загрузите скачанный `.jar`-файл в папку `/plugins/` вашего сервера (**Paper / Purpur 1.21+**).
   * *(Рекомендуется)* Установите **Vault** и плагин на экономику (например, **EssentialsX**), чтобы игроки могли передавать монеты прямо внутри окна обмена.
3. **Запустите и настройте:**
   * Перезапустите сервер, при необходимости настройте максимальную дистанцию обмена и шаг ставок валюты в `plugins/MirTimeTrade/config.yml` и выполните `/trade reload`.
