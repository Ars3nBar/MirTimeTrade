# 🤝 MirTimeTrade

**Безопасный GUI-обменник вещами и валютой между игроками** для серверов Minecraft **1.21+**.

### ✨ Возможности
* Удобное двустороннее окно обмена с визуальным таймером подтверждения (защита от подмены предметов в последнюю секунду).
* Поддержка передачи игровой валюты прямо внутри меню сделки.
* Автоматический возврат предметов в инвентарь при отмене или выходе игрока с сервера.
* Полная настройка сообщений и оформления в `config.yml`.

### ⌨ Команды и права
* `/trade <ник>` — предложить обмен игроку (`mirtime.trade.use`).
* `/trade accept` — принять входящий запрос на обмен.
* `/trade deny` — отклонить запрос.

### 📦 Установка
1. Скачайте `MirTimeTrade.jar` из вкладки **Actions**.
2. Закиньте файл в папку `plugins/` и перезагрузите сервер.
